# Predictive Profitability & Sales Modelling System

Machine learning project analysing e-commerce transaction data to predict profitability and identify business performance drivers.

## Technologies
- Python
- pandas
- scikit-learn
- Excel

## Models Used
- Linear Regression
- Logistic Regression
- Decision Trees

## Features
- Data cleaning and preprocessing
- Feature engineering
- Profitability prediction
- Model evaluation
- Business recommendations

## Outcome
Achieved a 94% module grade and produced business-focused recommendations through predictive modelling and statistical analysis.
